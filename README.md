# Дәстүр — каталог коллекции «Той»

Интерактивный каталог алкогольной продукции для торгового представителя. Девять позиций,
у каждой своя этикетка, посвящённая казахскому обычаю: орнамент, цвет-смысл и пожелание
на казахском с переводом.

Бренд «Дәстүр», производитель, цены и штрихкоды — условные, это концепт-дизайн.

Возможности страницы:

- шапка с золотой пылью, которая собирается в шесть орнаментов и реагирует на курсор;
- этикетки в SVG: фольгированный блеск, 3D-наклон, «живой» орнамент при наведении
  (свечение, бегущий по линиям свет, волны, кольца, параллакс);
- фильтры по категории и поводу;
- карточка позиции: этикетка, бутылка, контрэтикетка (EAN-13 с префиксом 487, место под УКМ);
- режим презентации на весь экран (стрелки, пробел, свайп, Esc);
- заявка в коробках с расчётом в бутылках и тенге и копированием текста;
- «Азбука орнамента» и «Цвет как смысл».

## Как открыть

Это один файл без сборки: откройте `index.html` в браузере или раздайте папку любым
статическим хостингом (GitHub Pages, Netlify, Cloudflare Pages). Шрифты — Google Fonts
(Unbounded, Forum, Golos Text).

## Перед печатью этикеток

- Казахские тексты и латиницу вычитать носителю языка.
- Предупреждения о вреде и обязательные реквизиты сверить с действующими редакциями
  техрегламента и Закона «О языках» на adilet.zan.kz.
