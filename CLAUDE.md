# Alco — каталог «Дәстүр», контекст проекта

## Что это
Интерактивный каталог алкогольной коллекции «Той» вымышленного бренда «Дәстүр» для торгового
представителя. Каждая из 9 этикеток посвящена казахскому обычаю. Язык страницы — русский,
названия и пожелания на этикетках — казахский (кириллица) + латиница 2021 года.

## Устройство
- Один файл `index.html`: свой CSS и JS внутри, без сборки и без библиотек. Шрифты — Google Fonts.
- Данные позиций — массив `P` в скрипте; орнаменты — `MOTIFS` (пути в квадрате 100×100,
  копии собираются матрицами `DOMMatrix`).
- Этикетка — `labelSVG()`, бутылка — `bottleSVG()`, контрэтикетка — `backHTML()`,
  штрихкод — `barcodeSVG()`/`ean13()`.
- Общие градиенты металла (`mg-*` в координатах этикетки, `mm-*` в координатах орнамента),
  фильтр свечения и бордюры лежат в скрытом `<svg id="defs">`.
- Анимация орнамента при наведении — CSS по селекторам `.sample:hover`, `.live`, `.lex-i:hover`;
  слои эмблемы: `.glow`, `.draw`, `.flow`.
- Презентация — фиксированный слой `#pres` (не `<dialog>`): fullscreen запрашивается на нём самом.
  Если перевести в fullscreen весь документ, он перекроет слайды.

## Решения (не ломать)
- Конфетти («дождик») убраны по просьбе заказчика — не возвращать.
- Разделы «Правила дизайна» и «Источники» со страницы убраны по просьбе заказчика.
- Детские, религиозные и траурные обряды в коллекцию не берутся.
- Космогонические знаки (солнце, шаңырақ) — только в верхней части этикетки; эмблемы симметричны.
- `prefers-reduced-motion` отключает анимации.
